# Sonora

Sitio público de **Sonora**, una aplicación de radio española en directo para
Android.

Este repositorio contiene **sólo la página pública y la política de
privacidad**. El código de la aplicación no está aquí.

- `docs/index.html` — portada
- `docs/privacidad.html` — política de privacidad, la URL que exige Google Play

Se publica con GitHub Pages desde `main`, carpeta `/docs`.
